# YouTube Spam Collection (UCI)

Bundled CSV files from the [UCI YouTube Spam Collection](https://archive.ics.uci.edu/dataset/380/youtube+spam+collection) (Alberto & Lochter, 2015). Used by the Packt `SpamDetectorNN.py` reference.

Columns: `COMMENT_ID`, `AUTHOR`, `DATE`, `CONTENT`, `CLASS` (`0` = ham, `1` = spam).
